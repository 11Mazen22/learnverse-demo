# Open WebUI and asset provenance

No Open WebUI source, component, stylesheet, logo, or archive content was copied into this redesign. The AI workspace is an independent React implementation using the existing Noata/Supabase/Fanar architecture. Consequently no Open WebUI BSD notice is newly required by this change. If future code reuse occurs, only the user-approved v0.6.5-or-earlier baseline may be considered, with its BSD-3-Clause notices preserved.

The Cairo font binaries were copied unchanged from existing repository vendor assets. Preserve upstream font licensing when distributing. ReactMarkdown, remark/rehype, highlight.js and KaTeX retain their package license files in dependency distributions. No Railway archive was available for inspection; no import is claimed.
